Справочник «Задачи»

Назначение: Учет задач из внешних систем («Mantis», «Jira» и др.), в рамках которых реализовывались или изменялись функции. Связывает разработку с проектным управлением. Каждая задача – это конкретный объем работ, приводящий к изменению функциональности системы.

Ключевые реквизиты:

·        Код (Номер): Номер задачи из внешней системы.

·        Наименование: Тема задачи.

·        Статус: Текущий статус задачи (связь со справочником «Статусы», например, «В работе», «Тестирование», «Закрыта»).

·        Содержание: Детальное описание задачи и дополнительные комментарии.

·        Обработано: Признак, что задача полностью описана в реестре. Автоматически проставляется при достижении определенных статусов (например, «Закрыта»).

·        Другим подрядчиком: Признак, что задача выполнялась сторонним исполнителем (не основным разработчиком).

·        Проект: Привязка к проекту (в рамках мультипроектности).

·        Ссылка: URL на задачу во внешней системе трекинга (например, «https://mantis.company.ru/view.php?id=1542»).

·        Инструкция: Статус наличия инструкции для задачи («Есть», «Нет», «Не требуется», «Требуется»).

·        Тестирование: Статус наличия тестирования по задаче («Есть», «Нет», «Не требуется», «Требуется»).

Правила работы:

·        Основной механизм связи «Задача – Функция – Объект» осуществляется через табличную часть «Функции и объекты задачи» в карточке.

·        При записи задачи данные из этой таблицы переносятся в регистр сведений «Реестр функций».

·        Для задач без изменений в конфигурации допустимо указывать функцию «нет изменений», объект «нет изменений», действие «нет действий».

Таблица «Функции и объекты задачи» – это Ключевой элемент связывания.

Например, Задача «MANTIS-1542»: «Реализовать систему скидок по карте лояльности».

1.      Первая строка таблицы:

a.      Функция: «Учет скидок по карте лояльности»;

b.      Объект: «Справочник КартыЛояльности»;

c.      Действие: «Создан».

2.      Вторая строка таблицы:

a.      Функция: «Учет скидок по карте лояльности»;

b.      Объект: «Документ Продажа»;

c.      Действие: «Изменен».

3.      Третья строка таблицы:

a.      Функция: «Учет скидок по карте лояльности»;

b.      Объект: «Общий модуль РасчетСкидок»;

c.      Действие: «Создан».

4.      Четвертая строка таблицы:

a.      Функция: «НСИ Контрагенты»;

b.      Объект: «Справочник Контрагенты»;

c.      Действие: «Изменен».
