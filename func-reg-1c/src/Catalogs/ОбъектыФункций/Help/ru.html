Справочник «Объекты функций»

Назначение: Хранит список объектов метаданных конфигурации (справочники, документы, отчеты и т.д.), которые реализуют функции. Объект описывает, где реализована функция.

Структура: Иерархия с ограничением в 2 уровня. Группы соответствуют типам метаданных.

Ключевые реквизиты:

·        Наименование: Имя объекта в конфигураторе.

·        Синоним: Понятное для пользователя название.

·        Типовой: Признак, является ли объект типовым или проектным.

·        Содержание: Описание назначения объекта.

Правила работы:

·        Типовые объекты подсвечиваются в форме списка цветом «топленое молоко».

·        Объекты вносятся интерактивно или загружаются с помощью обработки «Загрузка объектов».

·        Необходимо вносить только ключевые объекты, существенные для понимания изменений.

Пример заполнения:

·        Объект: «Справочник.КартыЛояльности».

·        Синоним: «Карты лояльности».

·        Типовой: Нет (разработан для проекта).

·        Содержание: «Хранение информации о картах лояльности клиентов».
