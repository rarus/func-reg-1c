Справочник «Проекты»

Назначение: Реализация мультипроектности. Позволяет вести несколько независимых реестров в одной базе.

Ключевые реквизиты:

·        Префикс: Буквенный код проекта (2-3 символа). Используется для быстрой идентификации элементов.

Правила работы:

·        Все основные объекты (Задачи, Функции, Объекты) должны быть привязаны к проекту.

·        В отчетах и АРМ доступен отбор по проекту.
