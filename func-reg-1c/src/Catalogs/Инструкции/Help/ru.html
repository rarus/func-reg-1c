Справочник «Инструкции»

Назначение: Учет документации (инструкций), созданной для функций системы. Управление документацией проекта. Обеспечивает контроль полноты и актуальности документации для каждой функции.

Ключевые реквизиты:

·        Номер: Идентификатор инструкции.

·        Статус: Статус инструкции (например, «Черновик», «Актуальная», «Устаревшая» и т.д.).

·        Адрес хранения: Ссылка на файл инструкции в сети или базе знаний.

·        Дата проверки: Дата последней актуализации инструкции.

·        Оценка, час: Трудозатраты на написание.

·        Содержание: Аннотация или краткое содержание.

Правила работы:

·        Связь инструкции с задачами и функциями устанавливается через регистр сведений «Инструкции», доступный из карточки инструкции.

·        Статус «Инструкции» в связанной задаче может обновляться автоматически при создании и привязке инструкции.

Полный процесс работы с инструкцией:

1.      Создание: Новая инструкция с статусом «Черновик».

2.      Наполнение: Указание авторов, содержания, адресов хранения.

3.      Связывание: Привязка к задачам и функциям через регистр.

4.      Согласование: Статус «На проверке».

5.      Публикация: Статус «Актуальна», размещение в базе знаний.

6.      Актуализация: Периодическая проверка, обновление.
