Обработка «Управление реестром функций» (Основной рабочий инструмент)

Назначение: Универсальное рабочее место для анализа и управления всеми данными реестра.

Интерфейс и правила работы:

1.      Левая панель («Настройки»):

a.      Режим отображения: Переключение между «Табличным документом» (сводный отчет) и «Списком регистра сведений» (для прямого редактирования).

b.      Система отборов: Деревья для отбора по Объекту, Задаче, Функции, Действию, Статусу, Автору и Проекту. Для каждого элемента можно установить флажок включения в отбор.

c.      Управление отборами: Кнопки «Установить/Снять флажки», «Свернуть/Развернуть дерево» для быстрого управления.

d.      Кнопка «Сбросить списки отборов»: Для очистки всех установленных фильтров.

2.      Правая панель («Данные»):

a.      Отображает данные в выбранном режиме («Табличный документ» или «Список»), с учетом установленных отборов.

b.      В режиме «Табличный документ» двойной клик по ячейке с действием позволяет его добавить или изменить.

3.      Панель ошибок:

a.      Автоматически проверяет корректность данных. Например, выявляет ошибки, когда один и тот же объект помечен как «Создан» в нескольких разных задачах.
