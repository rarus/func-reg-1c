Обработка «ЗагрузкаОбъектов»

Назначение: Загрузка списка объектов метаданных из внешнего источника.

Правила работы:

·        Для выгрузки данных из исходной конфигурации используется внешняя обработка «ПолучитьСписокМетаданныхДляЗагрузкиВРеестрФункций», которую можно скачать из данной обработки в режиме Предприятия.

·        Данные загружаются в формате JSON.

·        В процессе загрузки отображается прогресс-бар.
